# Screenshot aplikasi

Diambil pada 17 Oktober 2026 dari Duit Aing 1.1.0 yang berjalan di emulator Android, dengan resolusi 1080 × 2400 piksel.

Seluruh rekening, saldo, nama profil, transaksi, dan anggaran menggunakan data fiktif yang dibuat khusus untuk dokumentasi publik. Contoh percakapan Vina menggunakan mode lokal dan dataset yang sama. Screenshot berasal langsung dari aplikasi, bukan mockup.

- `home.png`: Beranda dan ringkasan saldo.
- `transactions.png`: Riwayat, pencarian, dan filter transaksi.
- `reports.png`: Laporan pengeluaran berdasarkan kategori.
- `assets.png`: Rekening dan aset.
- `vina.png`: Jawaban Vina lokal atas pertanyaan pengeluaran bulan berjalan.
- `settings.png`: Pengelompokan pengaturan aplikasi.

Klik gambar pada README utama untuk membuka file beresolusi penuh.
